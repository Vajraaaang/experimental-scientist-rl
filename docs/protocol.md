# Pilot protocol (declared before measurement)

The user requests runnable feasibility evidence before flagship expansion. The supplied Markdown supplies requirements. Its embedded Codex prompt is not a separate user instruction. The source file is preserved verbatim at the project root. No other user projects or private data are used.

The first scientific family consists of two feed-forward regulatory pathways: controls X0/X1 affect X4, controls X2/X3 affect X5, and both intermediates affect both outcomes. Four control-edge signs and one outcome-route sign are uncertain, giving 32 exact hypotheses. Edge magnitudes are 1.5 for control-to-proxy and 1.55 for proxy-to-outcome, rates are [1,1,1,1,1.2,1.2,.7,.7], and all baselines are .5. The complete support is public to the belief model, but its true index is never given. This is a finite-support inference diagnostic, not unseen-mechanism generalization. Mechanism-disjoint continuous-parameter manifests are reserved separately.

Targets are independently drawn as .5 +/- .08 on each outcome before admission. Admit a mechanism/target combination if some single final action has nominal RMSE <=.04 and improves MSE by at least .0001 over no intervention. Condition the belief prior on exactly this rule. Report admission mass for each target. No hidden feasibility indicator reaches a policy. This matched-baseline family has no baseline information when culture variation is disabled.

The 45 actions are 36 assays (no intervention or eight single suppressions, times 1/6, proxy or outcome pair) and nine commitments. Four assays maximum; budgets 8 and 16; eight cultures per assay; 32 independent final cultures for development. Setup baseline assay costs 3 units outside exploration budget (all eight variables, time zero). Report this separately. Initial readout SD .02; noise controls .08 and 10; culture offsets initially zero and then .03. All reference calculations float64 exponential Euler dt=.05. Compare dt/2 and DOP853. Independent RNG streams govern mechanisms, targets, baseline, exploration, measurement noise, policy sampling and final evaluation. Final draws may be paired across methods but never reused from exploration.

The primary setting uses lambda_c=.01, lambda_u=.05, loss scale100 and gamma1; cost sensitivity .005/.02. Tune fixed schedules using 24 calibration episodes, evaluate on 128 distinct development episodes (not new finite-support mechanisms). Both are explicitly finite-support diagnostics. Fixed search enumerates all first assays, all affordable ordered pairs via a beam search, then extends the best eight schedules to four assays; additionally include every repeated single-assay schedule and every affordable full-dose single-control identification subset. Label it tuned, not optimal. Fixed schedules always use their declared length; adaptive stopping is included in the adaptive strategy's claim and its cost must be reported.

Fixed, random, EIG and one-step VOI use the same posterior final selector. Additive identification is reported separately because it changes the estimator. Enumerate full-information choices privately and label the nominal reference approximate under culture variation. Examine cost-quality and utility separately. Bootstrap paired differences over development episodes conditional on finite support; such intervals do not quantify uncertainty over unseen mechanism groups. Mechanism-group inference is deferred to continuous holdouts. Gate C requires a positive paired 95% interval AND >=10% recovery of the prior-to-reference loss gap beyond the tuned fixed method on the primary setting. A positive difference in cost alone is amortized or stopping value, not necessarily improved assay selection. Gate B compares experiments with prior-informed commitment after cost. Gate C failure preserves the result and prevents scientific PPO scaling.

VOI integrates stratified hypothetical observations over all hypotheses with 12 noise draws/hypothesis/candidate. It is approximate one-step planning, not exact optimal planning. Recompute with more draws on selected cases to check sensitivity before larger banks. Prediction cache integrates each intervention once and retains endpoints at times1/6; panel changes do not rerun dynamics. With nonzero culture variation, Gaussian moments from 32 independent hypothetical cultures approximate the likelihood. This approximation requires coverage/ESS diagnostics and does not count as exact posterior inference. Actual purchased replicate readings are all used; lookahead approximates them by their mean.

Learning order: full-history actor-critic with explicit causal padding; then same-size recurrent architecture for imitation, PPO and imitation followed by PPO. Complete-episode sequences, valid dummy padding actions, exclusion of padding from every loss, exact mask recomputation, zero initial recurrent memory and terminal bootstrap checks are required. Small smoke runs establish execution only. Diagnostic delayed evidence removes the external-action memory channel. Any substantial scientific learning comparison requires gate C and multiple seeds. Complete rollouts and updates (including transfers, evaluation, checkpoints and synchronization) determine CPU/MPS choice. No silent MPS CPU fallback.

No locked-test results are used here. Later structure, range and simulator-shift suites require separate declarations and validation. No result concerns real biological effectiveness.
